Status: release candidate

Scope: Architecture hardening release candidate metadata and acceptance record

This release candidate records the targeted architecture hardening pass after the v0.2.3-rc1 Safe Mutation foundation. It does not promote the project to stable. The rc2 tag should be applied only after this version metadata commit is reviewed and accepted.

## Included Source Changes

- Runtime save/import persistence normalizes app state before saving or importing.
- Import invariant validation reports warnings without silently deleting orphan relationships.
- AI patch handling validates target values and references before apply.
- AI patch accept/reject status transitions are unified through the patch mutation flow.
- Handoff readiness changes are guarded through the handoff action instead of direct status mutation.
- Missing-id deletes across core entities are safely rejected without mutating state.
- Architecture hardening docs and tests capture the targeted guardrails for this pass.
